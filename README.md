# 우마무스메 라이브 콜 가이드

Vaundy 2026 Seoul 떼창 가이드의 구조를 바탕으로 만든, 곡 한 개짜리 콜 가이드입니다.
빌드 도구 없이 파일만 올리면 동작합니다 (GitHub Pages / Cloudflare Pages).

## 파일 구성

```
index.html            ← 본체 (이벤트 정보 · 곡 데이터 · 화면 · 동작 전부)
sw.js                 ← 오프라인 저장 (공연장에서 인터넷 없이도 가사 보기)
manifest.json         ← 홈 화면에 앱처럼 설치
icon-192.png / icon-512.png / apple-touch-icon.png
data/ms-victoria.json ← 가사 데이터 (직접 넣어야 함 — data 폴더 안내 참고)
images/notice/        ← 공지 이미지 (선택)
```

## 고치는 곳 (index.html 위쪽)

- `CONFIG` — 이벤트 이름, 공연 일정(카운트다운), 당일 타임라인, 장소, 링크, 공지 이미지.
  비워 두면 해당 카드가 화면에서 빠집니다.
- `SONGS` — 곡 정보와 기본 데이터. 곡을 늘리려면 같은 형식으로 한 덩어리 더 추가하면
  목록에 2번(검정 게이트)으로 붙습니다.
- 가사 줄 형식은 친구분 사이트의 JSON 저장 형식과 같습니다:
  `{ time, action, jp, kr, pron, call }`
- 줄 어디에든 `[oi] [clap] [wave] [jump] [cheer] [sing]` 을 적으면 아이콘이 들어갑니다.

## 가사 데이터 우선순위

1. 이 기기에서 "JSON 파일 불러오기"로 넣은 파일 (곡 목록 화면 아래)
2. `data/ms-victoria.json`
3. index.html 안의 기본 데이터 (타이밍 · 동작 · 콜만, 가사 없음)

## 다시 올릴 때

`sw.js`의 `CACHE_VERSION`을 꼭 올려 주세요 (v1 → v2). 그래야 이미 방문한 사람 폰에
"새 버전이 준비됐어요 · 새로고침" 안내가 뜹니다.

## 공지용 문구 예시

> 공연장은 데이터가 잘 안 터집니다. 집에서 미리 한 번 열어 두세요.
> 한 번 열어 두면 인터넷 없이도 가사와 콜이 보입니다. (영상만 인터넷이 필요해요)
